API REST - Gestión de productos

Desarrollada en Java Spring Boot, diseñada para manejar operaciones CRUD de productos. Arquitectura limpia y completamente "Dockerizada".

## Tecnologías Utilizadas
* **Java 21 & Spring Boot 3.3.4**
* **MySQL 8**
* **Docker & Docker Compose**
* **Swagger / OpenAPI**
* **Hibernate / Spring Data JPA**
* **Jakarta Validation**

## Cómo ejecutar el proyecto (Un solo clic)
1. Clona el repositorio.
2. Abre una terminal en la carpeta del proyecto y ejecuta: `docker-compose up -d`
3. Abre tu navegador en: `http://localhost:8080/swagger-ui.html`
